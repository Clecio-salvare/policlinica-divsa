# 🏥 Sistema de Agendamento - Policlínica PCPE

## 📌 Sobre o projeto
Sistema web desenvolvido para gerenciar o agendamento de consultas da Policlínica da Polícia Civil de Pernambuco (PCPE), atendendo servidores ativos e aposentados.

O sistema permite cadastro de usuários, triagem obrigatória para a Divisão de Saúde (DIVSA), agendamento por especialidade e controle administrativo completo.

---

## 🎯 Problema resolvido
O processo de agendamento era realizado manualmente, gerando:
- Filas e demora no atendimento
- Conflitos de horários
- Falta de controle dos atendimentos
- Retrabalho administrativo

---

## 💡 Solução proposta
Desenvolvimento de um sistema web com:
- Controle de usuários
- Agendamento online
- Bloqueio automático de horários
- Gestão de triagens
- Painel administrativo
- Geração de comprovante em PDF

---

## 🚀 Funcionalidades

### 👤 Usuário
- Cadastro e login
- Agendamento de consultas
- Triagem obrigatória (DIVSA)
- Emissão de comprovante em PDF

### 🩺 Sistema de Saúde
- Divisão entre:
  - DIVSA (multidisciplinar)
  - DIVMESO (médica)
- Controle de especialidades e profissionais

### 🛠️ Administrativo
- Visualização de agendamentos
- Concluir, cancelar ou marcar desistência
- Controle de triagens
- Relatórios mensais

---

## 🛠️ Tecnologias utilizadas
- HTML5
- TailwindCSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- jsPDF
- html2canvas
